## 1. Ensemble Models

**Definition:** combine predictions of several models into one final prediction; the hope is that individual mistakes partly cancel out (like asking several doctors).

- **Classification:** majority (hard) voting. Spam / Not spam / Spam → **Spam**.
- **Regression:** average. Rs 48L, 50L, 52L → **Rs 50L**.

### Handling a tie (4 models: LR, KNN, SVM, DT → Yes, Yes, No, No)
| Method | Idea | Example result |
|---|---|---|
| **Soft voting** | Average the predicted probabilities, pick the larger | P(Yes) = (0.80+0.70+0.35+0.25)/4 = **0.525** > P(No) = 0.475 → **Yes** |
| **Best model on validation set** | Keep aside a validation set; the most accurate model breaks ties | SVM has 18/20 = 90% (best) → SVM says No → **No** |

Validation data picks the tie-breaker; the test sample is only used for the final prediction.

### Three main approaches
| Approach | Examples | Training style |
|---|---|---|
| **Bagging** | Random Forest | Parallel, independent models on bootstrap samples |
| **Boosting** | AdaBoost, CatBoost, **Gradient Boosting**, XGBoost | Sequential, each model fixes the previous one's errors |
| **Stacking** | CNN ensemble + meta-model | Meta-model learns to combine base-model outputs |

### Bagging (Bootstrap AGGregatING)
- **Bootstrap sample:** pick rows randomly *with replacement* (a row is put back after being picked), usually same size as the original. Original A,B,C,D,E → e.g. B,D,B,A,E. Some rows repeat, some are missing (a 1000-row sample has < 1000 *distinct* rows).
- **Steps:** (1) create bootstrap samples → (2) train one model per sample (e.g. decision trees) → (3) combine by majority vote (or average).
  - D = {A..F}: Sample 1 = A,B,B,D,E,F; Sample 2 = A,C,C,D,E,F; Sample 3 = B,C,D,D,E,F.
  - Three trees say Yes, No, Yes → **Yes**.

### Out-of-Bag (OOB) error
A free validation estimate for bagging. A row is "out of bag" for a tree if that tree's bootstrap sample didn't contain it.

**Steps:** for each row → (1) find trees that did **not** train on it → (2) only those trees predict it → (3) majority vote, compare with true label. OOB error = wrong rows / total rows.

**Example (4 rows, 6 trees):**
| Row | Actual | OOB trees' votes | OOB vote | Correct? |
|---|---|---|---|---|
| A | Yes | Yes, Yes, No (Trees 2,4,6) | Yes | ✔ |
| B | No | No, Yes, No | No | ✔ |
| C | Yes | No, No, Yes | No | ✘ |
| D | No | No, No, Yes | No | ✔ |

**OOB error = 1/4 = 25%**

### Boosting — core idea
Train weak learners *sequentially*; each new learner focuses on the samples the previous ones got wrong. Final answer = combined (weighted) vote of all learners.

Intuition example (15 samples): Tree 1 gets 8 right, 7 wrong (I–O) → Tree 2 pays extra attention to I–O, now gets 11 right → Tree 3 focuses on its remaining errors, etc. A later tree can get previously-right samples wrong; that's fine.

### AdaBoost (worked example from slides)
Data (6 rows): A (High), B (High), C (Low), D (Low), E (High), F (Low). Initial weights **w = 1/6 each**.

**Formulas**
- Error: e = sum of weights of misclassified samples
- Classifier strength: **α = ½ · ln((1 − e)/e)**
- Wrong samples: w × e^α. Correct samples: w × e^(−α). Then **normalise** so weights sum to 1.
- Final prediction: class with the largest sum of α values.

| Round | Stump | Wrong | e | α | New weights |
|---|---|---|---|---|---|
| 1 | Green→High else Low | A | 1/6 | ½ ln 5 = **0.8047** | A = 0.50, others 0.10 |
| 2 | Male→High, Female→Low | B, D | 0.10+0.10 = 0.20 | ½ ln 4 = **0.6931** | A=0.3125, B=0.25, C=0.0625, D=0.25, E=0.0625, F=0.0625 |
| 3 | Height ≥ 1.6 → High | D, E | 0.25+0.0625 = 0.3125 | ½ ln 2.2 = **0.3942** | — |

*Round-1 check:* wrong A: (1/6)e^0.8047 = 0.3727; right B–F: (1/6)e^−0.8047 = 0.0745 each; total 0.7452; normalised A = 0.50, others 0.10.
*Round-2 check:* wrong ×2 (e^0.6931), right ×0.5; totals 0.80 → divide by 0.80.

**Predict new person (1.7 m, Green, Female):** C1 → High (0.8047), C2 → Low (0.6931), C3 → High (0.3942).
High = 0.8047+0.3942 = **1.1989** > Low = 0.6931 → **High**.

## 2. Gradient Boosting

Boosting for **regression** where each new tree is trained on the **residuals** (errors) of the current model, and added with a small learning rate.

**Residual = actual − current prediction.** Positive residual → prediction too low.

### Algorithm
1. **Initial prediction F₀ = mean of targets.**
2. Compute residuals.
3. Train a tree on (features → residuals). Each leaf outputs the **average residual** of the rows in it.
4. **Update:** F_new(x) = F_old(x) + η · h(x) (η = learning rate, 0.1 here).
5. Recompute residuals, repeat for Tree 2, 3, …
6. Final model: **F_M(x) = F₀ + η·h₁(x) + η·h₂(x) + … + η·h_M(x)**

### Worked example (predict weight, η = 0.1)
Actual weights: A 88, B 76, C 56, D 73, E 77, F 57.

**F₀ = 427/6 ≈ 71.17**

| Row | Actual | F₀ | Residual r₁ | Tree-1 leaf | F₁ = 71.17 + 0.1·leaf | r₂ = actual − F₁ |
|---|---|---|---|---|---|---|
| A | 88 | 71.17 | +16.83 | +16.83 | 72.85 | +15.15 |
| B | 76 | 71.17 | +4.83 | +4.83 | 71.65 | +4.35 |
| C | 56 | 71.17 | −15.17 | −14.67 (C,F avg) | 69.70 | −13.70 |
| D | 73 | 71.17 | +1.83 | +3.83 (D,E avg) | 71.55 | +1.45 |
| E | 77 | 71.17 | +5.83 | +3.83 | 71.55 | +5.45 |
| F | 57 | 71.17 | −14.17 | −14.67 | 69.70 | −12.70 |

Leaf averages: C,F = (−15.17−14.17)/2 = −14.67; D,E = (1.83+5.83)/2 = 3.83.

**Tree 2** (targets r₂): leaves C,F = (−13.70−12.70)/2 = −13.20; D,E = (1.45+5.45)/2 = +3.45; A and B stay in their own leaves (+15.15, +4.35).
F₂ for A: 72.85 + 0.1(15.15) = **74.37** (71.17 → 72.85 → 74.37, creeping toward 88).

**Predict new person (1.7 m, Green, Female):** Tree 1 → +4.83 leaf, Tree 2 → +4.35 leaf
F₂ = 71.17 + 0.1(4.83) + 0.1(4.35) = **72.09 kg**

**Key points**
- Small learning rate = slow, careful improvement (needs more trees, but generalises better).
- AdaBoost reweights *samples*; Gradient Boosting fits *residuals* (negative gradient of squared-error loss).

## 3. Random Forest

**Random Forest = Bagging + decision trees (+ random feature selection).**

1. Draw many bootstrap samples from the training data.
2. Grow a decision tree on each. At every split, consider only a **random subset of features** (this decorrelates the trees; this part is from standard theory, since the slide diagram is an image).
3. Prediction: **majority vote** (classification) or **average** (regression).
4. Estimate performance with **OOB error** (see section 1).

**Why it works:** individual deep trees have low bias but high variance; averaging many different trees cuts variance. Works for both classification and regression.

## 4. Bayesian Learning – Introduction

**Bayesian reasoning:** start with an initial belief (**prior**), update it when new evidence arrives, get an updated belief (**posterior**). Doctor example: flu is common (prior) + fever, cough, aches (evidence) → flu more likely (posterior).

**Why probability in ML:**
- Some algorithms use it directly: **Naïve Bayes**, **HMMs**.
- It also helps analyse others: NN softmax/sigmoid outputs are probabilities; weights are randomly initialised from distributions.
- Real data has **incomplete information** (limited examples) and **noise/errors** (blurry images, wrong labels, faulty sensors), so predictions are uncertain.

### Probability basics
| Concept | Formula / meaning |
|---|---|
| Conditional probability | P(A\|B) = P(A ∩ B) / P(B), P(B) > 0 |
| Addition theorem | P(A ∪ B) = P(A) + P(B) − P(A ∩ B) |
| Independent events | P(A\|B) = P(A); P(A ∩ B) = P(A)·P(B) |
| General multiplication | P(A ∩ B) = P(A)·P(B\|A) |
| Mutually exclusive | A ∩ B = ∅ → P(A ∩ B) = 0 |
| Collectively exhaustive | A ∪ B = S → P(A ∪ B) = 1 |
| IID | Independent (one sample tells nothing about another) **and** identically distributed (same underlying distribution). Standard ML assumes IID train/test data. |

*Even/odd on a die:* mutually exclusive and collectively exhaustive.

### Total Probability Theorem
If A₁…Aₙ are non-overlapping and cover everything:

**P(B) = Σᵢ P(Aᵢ) · P(B | Aᵢ)**

*Derivation:* B = (B∩A) ∪ (B∩Aᶜ) → P(B) = P(B∩A) + P(B∩Aᶜ), and P(B∩A) = P(A)P(B|A).

**Example (assignment on time):** P(A) = 0.45 (internet), P(B|A) = 0.90, P(B|Aᶜ) = 0.42
P(B) = 0.45(0.90) + 0.55(0.42) = 0.405 + 0.231 = **0.636**

### Bayes' Theorem
**P(A|B) = P(B|A)·P(A) / P(B)**

In learning terms (h = hypothesis, D = data):

**P(h|D) = P(D|h)·P(h) / P(D)** → **Posterior = Likelihood × Prior / Evidence**

- P(h) prior · P(D|h) likelihood · P(D) evidence · P(h|D) posterior.
- A *hypothesis* is a rule/model, e.g. h₁: "spam if contains 'free prize'".

**Continuing the assignment example:** P(A|B) = 0.90 × 0.45 / 0.636 = 0.405/0.636 ≈ **0.6368** (belief in internet rises from 45% → 63.68% after learning the assignment was on time).

**Spam example:** P(spam) = 0.2, P(prize|spam) = 0.6, P(prize|not spam) = 0.1.
P(prize) = 0.2(0.6) + 0.8(0.1) = 0.12 + 0.08 = 0.20
P(spam|prize) = 0.12 / 0.20 = **0.60** (prior 20% → posterior 60%).

## 5. Bayes Optimal Classifier

MAP picks **one** hypothesis (highest posterior) and uses only it. **Bayes Optimal combines ALL hypotheses**, weighted by their posteriors, and picks the class with the highest total support.

**v_BO = argmax over vⱼ ∈ V of  Σ_{hᵢ ∈ H} P(vⱼ | x, hᵢ) · P(hᵢ | D)**

### Example 1
| Hypothesis | P(hᵢ\|D) | Prediction for X |
|---|---|---|
| h₁ | 0.40 | Positive |
| h₂ | 0.30 | Negative |
| h₃ | 0.30 | Negative |

- **MAP:** picks h₁ → **Positive**.
- **Bayes Optimal:** Positive = 0.40; Negative = 0.30+0.30 = 0.60 → **Negative**.

### Example 2 (4 hypotheses, 3 classes)
Weights: h₁ 0.4, h₂ 0.3, h₃ 0.2, h₄ 0.1.

| | P(v₁\|x,h) | P(v₂\|x,h) | P(v₃\|x,h) |
|---|---|---|---|
| h₁ | 0.5 | 0.3 | 0.2 |
| h₂ | 0.1 | 0.4 | 0.5 |
| h₃ | 0.5 | 0.4 | 0.1 |
| h₄ | 0.1 | 0.3 | 0.6 |

- v₁ = 0.5(0.4)+0.1(0.3)+0.5(0.2)+0.1(0.1) = **0.34**
- v₂ = 0.3(0.4)+0.4(0.3)+0.4(0.2)+0.3(0.1) = **0.35**
- v₃ = 0.2(0.4)+0.5(0.3)+0.1(0.2)+0.6(0.1) = **0.31**
→ **v₂**. (The slide's last row is shown with different numbers in one place, see [typos](#16-slide-typos-to-watch-for).)

### Example 3 (three neural nets, weights ∝ accuracy)
Accuracies 90, 80, 60 → weights 90/230, 80/230, 60/230.
Score(+) = (0.8·90 + 0.4·80 + 0.2·60)/230 = 116/230 = **0.5043**
Score(−) = (0.2·90 + 0.6·80 + 0.8·60)/230 = 114/230 = **0.4957** → **Positive**

### Gibbs Algorithm
Bayes optimal is the best achievable but **costly** (needs a posterior for every h in H). **Gibbs:** randomly pick **one** hypothesis *according to its posterior probability* and classify with it.
- h₁ (40%) → Positive; h₂, h₃ (30% each) → Negative.
- MAP always picks the top hypothesis; Gibbs samples one randomly in proportion to posteriors.
- (Standard result: Gibbs' expected error is at most twice the Bayes-optimal error.)

### Maximum Likelihood ⇒ Least Squared Error
Assume target = model prediction + Gaussian noise: **dᵢ = h(xᵢ) + eᵢ, eᵢ ~ N(0, σ²)** ⇒ dᵢ | xᵢ,h ~ N(h(xᵢ), σ²).

1. Likelihood: p(D|h) = Πᵢ (1/√(2πσ²)) · exp(−(dᵢ − h(xᵢ))² / 2σ²)
2. Take ln (product → sum): Σᵢ [ −½ ln(2πσ²) − (dᵢ − h(xᵢ))²/2σ² ]
3. Drop constant terms.
4. Maximising a negative = minimising the positive:

**h_ML = argmin_h Σᵢ (dᵢ − h(xᵢ))²**

**Maximum likelihood under Gaussian noise = least squared error.**
Example: errors 1 and −2 → SSE = 1 + 4 = 5.

## 6. Bayesian Learning – MAP and ML

When there are several candidate hypotheses, how do we choose?

| | Picks hypothesis maximising | Formula |
|---|---|---|
| **MAP** (Maximum A Posteriori) | posterior ∝ likelihood × prior | **h_MAP = argmax_{h∈H} P(D\|h)·P(h)** |
| **ML** (Maximum Likelihood) | likelihood only | **h_ML = argmax_{h∈H} P(D\|h)** |

**Derivation of MAP:** h_MAP = argmax P(h|D) = argmax P(D|h)P(h)/P(D). P(D) is the same for every h, so drop it.

**If all priors are equal, P(hᵢ) = P(hⱼ), MAP = ML.**

| Case | h₁: P(D\|h), P(h) → score | h₂ | ML | MAP |
|---|---|---|---|---|
| Unequal priors | 0.80, 0.10 → 0.08 | 0.40, 0.90 → 0.36 | h₁ | **h₂** |
| Equal priors (0.5) | 0.80 → 0.40 | 0.40 → 0.20 | h₁ | h₁ |

### Cancer-test example (classic!)
Given: P(cancer) = 0.008; P(+|cancer) = 0.98; P(−|no cancer) = 0.97 → P(+|no cancer) = 0.03.

- P(cancer ∩ +) = 0.008 × 0.98 = **0.00784**
- P(no cancer ∩ +) = 0.992 × 0.03 = **0.02976**
- P(+) = 0.00784 + 0.02976 = **0.0376**
- P(cancer | +) = 0.00784/0.0376 = **20.85%**
- P(no cancer | +) = 0.02976/0.0376 = **79.15%**

→ **MAP = no cancer**, even after a positive test, because cancer is so rare (low prior). ML alone would say "cancer" (0.98 > 0.03).

### Brute-Force MAP
Check **every** hypothesis in H, compute its posterior, pick the max.

**Setup:** H = {h₁: spam if prize, h₂: spam if link, h₃: spam if prize AND link, h₄: always not-spam}. Equal priors P(h) = 1/|H| = 0.25.

Training data: E1 (prize=Yes, link=Yes) → Spam; E2 (prize=No, link=Yes) → Not spam.

| Rule | E1 | E2 | Consistent? |
|---|---|---|---|
| h₁ | Spam | Not spam | ✔ |
| h₂ | Spam | Spam | ✘ |
| h₃ | Spam | Not spam | ✔ |
| h₄ | Not spam | Not spam | ✘ |

**Assumption:** P(D|h) = 1 if h is consistent, 0 otherwise. Version space VS = {h₁, h₃}.
P(D) = Σ P(D|h)P(h) = 0.25 + 0.25 = 0.50 = (#consistent)/|H|.
Posterior: P(h₁|D) = 1 × 0.25/0.50 = **0.50**, P(h₃|D) = **0.50**, P(h₂|D) = P(h₄|D) = **0**.
→ h₁ and h₃ tie, so both are MAP hypotheses.

## 7. Naïve Bayes Classifier

**Idea:** classify using Bayes' theorem, but assume features are **conditionally independent given the class** (that's the "naïve" part).

### Derivation
Instance X = (a₁, …, a_d), classes V.
1. v_MAP = argmax P(vⱼ | X) = argmax P(X|vⱼ)P(vⱼ)/P(X)
2. P(X) is common to all classes → drop it: **v_MAP = argmax P(X|vⱼ)·P(vⱼ)**
3. Expand: P(a₁,…,a_d | vⱼ) = P(a₁|vⱼ)·P(a₂|a₁,vⱼ)·P(a₃|a₁,a₂,vⱼ)…
4. Naïve assumption: P(aₖ | earlier a's, vⱼ) = P(aₖ|vⱼ)

**v_NB = argmax_{vⱼ∈V}  P(vⱼ) · Π_{i=1..d} P(aᵢ | vⱼ)**

### Types
| Type | Use when |
|---|---|
| **Gaussian NB** | Continuous numerical features (height, temperature, sensor values) |
| **Multinomial NB** | Discrete counts / frequencies (word counts in text) |
| **Bernoulli NB** | Binary (0/1) features |
| **Categorical NB** | Categorical features (Outlook = Sunny/Overcast/Rain) |

### Example 1: Play Tennis (14 days; 9 Yes, 5 No)
Predict for **X = (Sunny, Cool, High, Strong)**.

| Feature | P(·\|Yes) | P(·\|No) |
|---|---|---|
| Outlook = Sunny | 2/9 | 3/5 |
| Temp = Cool | 3/9 | 1/5 |
| Humidity = High | 3/9 | 4/5 |
| Wind = Strong | 3/9 | 3/5 |

- Score(Yes) = 9/14 × 2/9 × 3/9 × 3/9 × 3/9 ≈ **0.0053**
- Score(No) = 5/14 × 3/5 × 1/5 × 4/5 × 3/5 ≈ **0.0205**
- Normalise: P(Yes|X) ≈ **20.5%**, P(No|X) ≈ **79.5%** → **PlayTennis = No**

*Full conditional tables (for other questions):*
Outlook (Y/N): Sunny 2/9, 3/5 · Overcast 4/9, 0 · Rain 3/9, 2/5.
Temp: Hot 2/9, 2/5 · Mild 4/9, 2/5 · Cool 3/9, 1/5.
Humidity: High 3/9, 4/5 · Normal 6/9, 1/5.
Wind: Strong 3/9, 3/5 · Weak 6/9, 2/5.

### Example 2: Economy classification (9 rows; 3 Great, 3 OK, 3 Bad)
Predict for **X = (IT = Good, Chemicals = Avg, Crops = Good, Exports = Avg)**.

- Score(Great) = 3/9 × 2/3 × 2/3 × 2/3 × 1/3 ≈ **0.03292**
- Score(OK) = 3/9 × 1/3 × 1/3 × 2/3 × 2/3 ≈ **0.01646**
- Score(Bad) = 3/9 × 1/3 × 3/3 × 1/3 × 3/3 ≈ **0.03704**
- Total ≈ 0.08642 → Great 38.1%, OK 19.0%, Bad 42.9% → **Economy = Bad**

### Example 3: Text classification (Campaigning vs Law & Order) with Laplace smoothing
Training docs → after stop-word removal:
- Campaigning: D1 {inspiring, address}, D2 {aggressive, speech}, D4 {cowardly, speech}
- Law & Order: D3 {cowardly, act}, D5 {threatening, speech}, D6 {act, aggression}

Priors: 3/6 = ½ each. Vocabulary |V| = 7. Total words per class = 6.

**Zero-frequency problem:** P(threatening | Campaigning) = 0/6 = 0 → wipes out the whole product.
**Laplace (add-one) smoothing:** **P(w|C) = (count(w,C) + 1) / (total words in C + |V|)**, denominator = 6 + 7 = 13 for both classes.

| Word | Campaigning | Law & Order |
|---|---|---|
| Aggressive | 2/13 | 2/13 |
| Threatening | 1/13 | 2/13 |
| Address | 2/13 | 1/13 |

- Score(Campaigning) = ½ × 2/13 × 1/13 × 2/13 ≈ 0.000910
- Score(Law & Order) = ½ × 2/13 × 2/13 × 1/13 ≈ 0.000910
→ **50% / 50% — a tie**; no unique winner.

**Remember:** if a probability is 0 → use Laplace smoothing; for long products of tiny numbers, work with logs.

## 8. Expectation Maximization

**Problem:** learn model parameters when some information (e.g. class labels) is **hidden/missing**.
- To learn each class's pattern, e.g. P(prize | Spam), you need the labels.
- To estimate labels, P(Spam | prize), you need the pattern.
- Chicken-and-egg ⇒ **EM** iterates between the two.

### The two steps
| Step | What it does |
|---|---|
| **Initialise** | Pick starting parameter values (can be random) |
| **E-step (Expectation)** | Using current parameters + data, estimate the **probabilities of the hidden information** |
| **M-step (Maximization)** | Using those estimates, **update parameters** so the model better explains the data |
| **Repeat** | Until parameters change very little (convergence) |

Hidden values are still uncertain, so EM uses their **probabilities** (soft/expected counts).

### Two-coin example
5 experiments × 10 tosses; each from coin A or B (θ_A, θ_B = P(head)).

| Exp | Flips | H | T |
|---|---|---|---|
| 1 | HTTTHHTHTH | 5 | 5 |
| 2 | HHHHTHHHHH | 9 | 1 |
| 3 | HTHHHHHTHH | 8 | 2 |
| 4 | HTHTTTHHTT | 4 | 6 |
| 5 | THHHTHHHTH | 7 | 3 |

**If coin identity is known:** A = exps 2,3,5 → θ_A = 24/30 = **0.8**; B = exps 1,4 → θ_B = 9/20 = **0.45**.

**Identity hidden → EM.** Start: **θ_A = 0.6, θ_B = 0.5** (equal prior for A, B).

**E-step for exp 1 (5H, 5T):**
- P(E|A) = 0.6⁵ · 0.4⁵ = 0.0007963
- P(E|B) = 0.5⁵ · 0.5⁵ = 0.0009766
- P(A|E) = 0.0007963/(0.0007963+0.0009766) = **0.44915**, P(B|E) = **0.55085**
- Expected heads from A = 5 × 0.44915 = **2.246**, tails from A = 2.246; heads from B = 2.754, tails from B = 2.754.

**All rows (E-step):**
| Exp | H, T | P(A) | P(B) | Exp. H (A) | Exp. T (A) | Exp. H (B) | Exp. T (B) |
|---|---|---|---|---|---|---|---|
| 1 | 5, 5 | 0.44915 | 0.55085 | 2.246 | 2.246 | 2.754 | 2.754 |
| 2 | 9, 1 | 0.80499 | 0.19501 | 7.245 | 0.805 | 1.755 | 0.195 |
| 3 | 8, 2 | 0.73347 | 0.26653 | 5.868 | 1.467 | 2.132 | 0.533 |
| 4 | 4, 6 | 0.35216 | 0.64784 | 1.409 | 2.113 | 2.591 | 3.887 |
| 5 | 7, 3 | 0.64722 | 0.35278 | 4.531 | 1.942 | 2.469 | 1.058 |
| **Total** | | | | **21.297** | **8.572** | **11.703** | **8.428** |

**M-step:** θ_A = 21.297/(21.297+8.572) ≈ **0.713**, θ_B = 11.703/(11.703+8.428) ≈ **0.581**.
That's one iteration (0.60 → 0.713, 0.50 → 0.581). Repeat with the new values until convergence.

## 9. Gaussian Mixture Models (GMMs)

**GMM:** data is assumed to come from a **mixture of Gaussians**. Unknown: each Gaussian's **mean μⱼ, variance σⱼ², mixture weight πⱼ**, and which Gaussian generated each point. **EM learns these.**

- πⱼ = probability that Gaussian j is chosen to generate a data point (Σπⱼ = 1).
- Univariate Gaussian: **N(x | μ, σ²) = (1/√(2πσ²)) · exp(−(x−μ)²/(2σ²))**; μ = Σxᵢ/n, σ² = Σ(xᵢ−μ)²/n
- Multivariate: mean vector μ and covariance matrix Σ (variances on the diagonal, covariances off it).

### EM for GMM
**E-step (responsibility / membership probability):**

**rᵢⱼ = πⱼ · N(xᵢ | μⱼ, σⱼ²) / Σ_{ℓ=1..K} πℓ · N(xᵢ | μℓ, σℓ²)**

**M-step:**
- **μⱼ_new = Σᵢ rᵢⱼ xᵢ / Σᵢ rᵢⱼ**
- **πⱼ_new = Σᵢ rᵢⱼ / n**
- **σⱼ²_new = Σᵢ rᵢⱼ (xᵢ − μⱼ_new)² / Σᵢ rᵢⱼ** (when variances are unknown; fixed at 0.5 in the example)

### Worked example (fruit weights x = 2, 4, 7; two Gaussians)
Start: μ₁ = 3, μ₂ = 6, σ₁² = σ₂² = 0.5 (fixed), π₁ = π₂ = 0.5.
Constant 1/√(2π·0.5) = 1/√π ≈ 0.564190; denominator 2σ² = 1.

For x₁ = 2: f₁(2) = 0.56419·e^(−1) ≈ **0.207554**; f₂(2) = 0.56419·e^(−16) ≈ **6.349×10⁻⁸**.
r₁₁ = 0.5(0.207554) / [0.5(0.207554) + 0.5(6.349×10⁻⁸)] ≈ **0.9999997**

| xᵢ | r_i1 (G₁) | r_i2 (G₂) |
|---|---|---|
| 2 | 0.999999694 | 0.000000306 |
| 4 | 0.952574 | 0.047426 |
| 7 | 0.000000306 | 0.999999694 |

Sums: Σr_i1 ≈ 1.953, Σr_i2 ≈ 1.047. Σ x·r_i1 ≈ 5.812, Σ x·r_i2 ≈ 7.188.
- **μ₁ = 5.812/1.953 ≈ 2.976**
- **μ₂ = 7.188/1.047 ≈ 6.865**
- **π₁ = 1.953/3 = 0.651**, **π₂ = 1.047/3 = 0.349**

### Link to K-means
GMM = **soft** clustering (each point has a probability for each cluster); K-means = **hard** assignment. EM for GMM generalises k-means.

## 10. Introduction to Markov Models

**Idea:** use the present to predict what happens next. It gives a *probability* for each next state, never a certainty (Sunny today → 60% Sunny, 30% Cloudy, 10% Windy tomorrow).

### IID vs Markov
- Standard ML assumes **IID** examples. This fails for time series (audio/video), words in a sentence, DNA base pairs, weather. Consecutive days are *not* independent, and seasons mean days are *not identically distributed* (summer 0.8 Sunny vs winter 0.3).
- **Markov models do not require IID.**

### Stochastic process
A sequence/collection of random variables over time X₁, X₂, X₃, … on a common state space (e.g. coin tosses H/T; weather S/C/W).
**Stochastic process + Markov property = Markov process.**

### Markov (first-order) assumption
**P(X_{t+1} | X_t, X_{t−1}, …, X₁) = P(X_{t+1} | X_t)**

Given the present, the past gives no extra information. (k-th order Markov = use last k states.)

### Markov chain = discrete-time stochastic process with Markov property
Components:
- **Q** – set of states (e.g. {Sunny, Cloudy, Windy})
- **π** – initial distribution
- **A** – N×N transition matrix, a_ij = P(next = j | current = i); each row sums to 1

Prediction: today = Sunny → use row 1 of A. Tomorrow is Cloudy → throw away yesterday, use row 2.

**Sequence likelihood:** P(q₁ q₂ … q_T) = π(q₁) · a_{q₁q₂} · a_{q₂q₃} ⋯ a_{q_{T−1}q_T}

### Learning π and A from data (14 sequences of 5 days)
Sequences: SCWSC, SWCSS, WCSWC, CSCWC, CWSSW, WCSCC, WCCWS, WCWCS, SWCWS, WWCCS, CCSWS, WCSWS, WSWCS, WSWSW

**π (count first states):** S = 3, C = 3, W = 8 → π = (3/14, 3/14, 8/14)

**A (count transitions; 4 per sequence = 56 total):**
| From ↓ / To → | S | C | W | Total |
|---|---|---|---|---|
| Sunny | 2 | 4 | 9 | 15 |
| Cloudy | 9 | 4 | 6 | 19 |
| Windy | 9 | 12 | 1 | 22 |

Divide by row totals: Sunny row = (2/15, 4/15, 9/15), Cloudy = (9/19, 4/19, 6/19), Windy = (9/22, 12/22, 1/22).

I recounted these transitions in code and they match the slide.

**Training vs prediction:** train by counting starts and transitions in history; at prediction time use only the *current* state's row.

## 11. Introduction to HMM

In a Markov chain you *see* the state. In a **Hidden Markov Model** the states are **hidden**; you only see **observations** that each state emits with some probability.

Example: hidden weather (Sunny/Rainy) → observed mood (Happy/Grumpy). Patient's hidden health state → observed symptom severity. Speech: hidden sounds → observed audio.

### HMM parameters λ = (A, B, π)
| Symbol | Meaning |
|---|---|
| N | number of hidden states S₁…S_N |
| M | number of observation symbols |
| **A** (N×N) | transition probabilities a_ij = P(q_{t+1} = Sⱼ \| q_t = Sᵢ) |
| **B** (N×M) | emission probabilities bⱼ(o) = P(observe o \| state Sⱼ) |
| **π** | initial state probabilities |
| O = o₁…o_T | observation sequence; Q = q₁…q_T hidden state sequence |

**Two assumptions:** (1) Markov: next state depends only on the current state. (2) Output independence: an observation depends only on the current state.

### The 3 classic HMM problems
| # | Problem | Question | Algorithm |
|---|---|---|---|
| 1 | **Likelihood** | P(O \| λ)? | Forward (or Backward) |
| 2 | **Decoding** | Best hidden state sequence for O? | Viterbi |
| 3 | **Learning** | Find λ that maximises P(O \| λ) | Baum-Welch (EM) |

### Running example used in the slides (⚙️ derived)
States: **Sunny (S), Rainy (R)**. Observations: **Happy (H), Grumpy (G)**. Observation sequence **(H, G, H)**.

I recovered these values by working backwards from the slide's numbers (e.g. α₁(S) = 2/3 × 0.8 = 8/15, β₂ = 0.72, 0.56). They reproduce every number in the Forward, Backward and Viterbi tables:

| | Sunny | Rainy | | | Happy | Grumpy |
|---|---|---|---|---|---|---|
| π | 2/3 | 1/3 | | **B: Sunny** | 0.8 | 0.2 |
| **A: from Sunny** | 0.8 | 0.2 | | **B: Rainy** | 0.4 | 0.6 |
| **A: from Rainy** | 0.4 | 0.6 | | | | |

### Where this is used
Speech recognition, POS tagging, DNA sequences, gesture/face-expression recognition, gait identification, patient progression.

### Practical issues
- What states mean: no unique answer, designer's choice.
- How many hidden states: domain knowledge + trial and error.
- **Numerical underflow:** products of many small probabilities → use **log probabilities**.
- Many architectures possible (e.g. fully connected vs left-to-right); the designer chooses.

**Typical workflow:** define problem → define observations → prepare sequences → choose states → train (Problem 3, maybe 2) → validate (Problem 1) → iterate → use.

## 12. The Likelihood Problem (Forward & Backward)

**Goal:** compute **P(O | λ)**, the probability that the HMM generates the observation sequence O. (High likelihood = typical sequence, low = unusual.)

### Brute force
Sum over **every** possible state sequence Q:

**P(O|λ) = Σ_Q P(O|Q,λ)·P(Q|λ)**
For (H, G, H) with N = 2, T = 3 → 2³ = 8 paths, e.g. π(S)·b_S(H)·a_SS·b_S(G)·a_SS·b_S(H) + …
- Each path: ~2T multiplications → total **≈ 2T · N^T**, i.e. **O(T·N^T), exponential**.

Many terms repeat (e.g. π(S₁)·b₁(o₁) appears in the first 4 terms) → dynamic programming.

### Forward algorithm
**αₜ(j) = P(o₁,…,oₜ, qₜ = Sⱼ | λ)**: probability of seeing the first t observations **and** being in state j at time t.

1. **Initialisation:** α₁(j) = πⱼ · bⱼ(o₁)
2. **Recursion:** **αₜ(j) = [ Σᵢ α_{t−1}(i) · aᵢⱼ ] · bⱼ(oₜ)**, t = 2…T
3. **Termination:** **P(O|λ) = Σⱼ α_T(j)**

**Key idea:** at each t, everything needed for the next step is compressed into N numbers. Each costs O(N) → **O(N²) per step, O(N²T) total** (vs O(T·N^T)).

**Worked example (H, G, H):**
| | t=1 (H) | t=2 (G) | t=3 (H) |
|---|---|---|---|
| α(Sunny) | 2/3×0.8 = 8/15 = **0.5333** | (0.5333×0.8 + 0.1333×0.4)×0.2 = **0.096** (12/125) | (0.096×0.8 + 0.112×0.4)×0.8 = **0.09728** (304/3125) |
| α(Rainy) | 1/3×0.4 = 2/15 = **0.1333** | (0.5333×0.2 + 0.1333×0.6)×0.6 = **0.112** (14/125) | (0.096×0.2 + 0.112×0.6)×0.4 = **0.03456** (108/3125) |

**P(O|λ) = 0.09728 + 0.03456 = 0.13184**

### Backward algorithm
**βₜ(i) = P(o_{t+1},…,o_T | qₜ = Sᵢ, λ)**: probability of the *future* observations given you're in state i at time t.

1. **Initialisation:** β_T(i) = 1
2. **Recursion:** **βₜ(i) = Σⱼ aᵢⱼ · bⱼ(o_{t+1}) · β_{t+1}(j)**, t = T−1 … 1
3. **Termination:** **P(O|λ) = Σᵢ πᵢ · bᵢ(o₁) · β₁(i)**

**Worked example:**
| | t=1 | t=2 | t=3 |
|---|---|---|---|
| β(Sunny) | 0.1824 | 0.72 | 1 |
| β(Rainy) | 0.2592 | 0.56 | 1 |

- β₂(S) = a_SS·b_S(H)·1 + a_SR·b_R(H)·1 = 0.8(0.8) + 0.2(0.4) = 0.72
- β₂(R) = 0.4(0.8) + 0.6(0.4) = 0.56
- β₁(S) = 0.8(0.2)(0.72) + 0.2(0.6)(0.56) = 0.1152 + 0.0672 = 0.1824
- β₁(R) = 0.4(0.2)(0.72) + 0.6(0.6)(0.56) = 0.0576 + 0.2016 = 0.2592

### Using α and β together (the "important result")
At **any** time t: **P(O|λ) = Σⱼ αₜ(j) · βₜ(j)** (dot product of the α column and β column).
At t = 1: 0.5333 × 0.1824 + 0.1333 × 0.2592 = 0.09728 + 0.03456 = **0.1318** ✔ same as forward.

## 13. The Decoding Problem (Viterbi)

**Goal:** given O and λ, find the **most likely hidden state sequence Q\* = argmax_Q P(Q | O, λ)** (equivalently argmax P(Q, O | λ)).

**Brute force:** evaluate all N^T sequences, pick the best — exponential. It's the same enumeration as the likelihood problem, except that likelihood **sums** over sequences while decoding takes the **max**.

### Viterbi algorithm (dynamic programming + back-pointers)
**δₜ(j) = probability of the best path ending in state j at time t** (having produced o₁…oₜ).
**ψₜ(j) = back-pointer**: which previous state gave that best path.

1. **Initialisation:** δ₁(j) = πⱼ · bⱼ(o₁), ψ₁(j) = 0
2. **Recursion:** **δₜ(j) = maxᵢ [ δ_{t−1}(i) · aᵢⱼ ] · bⱼ(oₜ)**, **ψₜ(j) = argmaxᵢ [ δ_{t−1}(i) · aᵢⱼ ]**
3. **Termination:** P\* = maxⱼ δ_T(j); q_T\* = argmaxⱼ δ_T(j)
4. **Backtrack:** q_t\* = ψ_{t+1}(q_{t+1}\*), t = T−1 … 1

**Complexity: O(N²T)** — same as forward, with **max instead of sum**.

**Worked example (H, G, H):**
| | t=1 (H) | t=2 (G) | t=3 (H) |
|---|---|---|---|
| δ(Sunny) | 8/15 | max(8/15·0.8, 2/15·0.4)·0.2 = **32/375 ≈ 0.0853** (from S) | max(32/375·0.8, 8/125·0.4)·0.8 = **512/9375 ≈ 0.0546** (from S) |
| δ(Rainy) | 2/15 | max(8/15·0.2, 2/15·0.6)·0.6 = **8/125 = 0.064** (from S) | max(32/375·0.2, 8/125·0.6)·0.4 = **144/9375 ≈ 0.0154** (from R) |

Best final: δ₃(Sunny) = 0.0546 → backtrack: ψ₃(S) = S, ψ₂(S) = S.
**Best state sequence = Sunny → Sunny → Sunny** (prob ≈ 0.0546).

*Forward vs Viterbi:* Forward Σ over paths (total P(O)). Viterbi max over paths (single best path). Viterbi's P\* is always ≤ forward's P(O).

## 14. HMM Learning Problem (Baum-Welch)

**Goal:** given observation sequence(s) and the number of states, **estimate λ = (A, B, π)** that maximises P(O|λ). The state sequence is hidden, so we can't just count. Use **EM**.

**Baum-Welch = EM for HMMs.** Start with an initial guess for A, B, π and repeatedly improve it. (Formulas below are the standard ones; the slide versions are images.)

### Quantities
- **γₜ(j) = P(qₜ = Sⱼ | O, λ)** = αₜ(j)·βₜ(j) / P(O|λ): probability of being in state j at time t given the whole sequence.
- **ξₜ(i,j) = P(qₜ = Sᵢ, q_{t+1} = Sⱼ | O, λ)** = αₜ(i)·aᵢⱼ·bⱼ(o_{t+1})·β_{t+1}(j) / P(O|λ): probability of transition i → j at time t.

### E-step
Run forward and backward passes with the current λ, then compute γ and ξ for all t.

### M-step (re-estimation)
- **π̂ᵢ = γ₁(i)**
- **âᵢⱼ = Σ_{t=1..T−1} ξₜ(i,j) / Σ_{t=1..T−1} γₜ(i)**: expected i→j transitions ÷ expected transitions out of i
- **b̂ⱼ(k) = Σ_{t : oₜ = vₖ} γₜ(j) / Σ_{t=1..T} γₜ(j)**: expected times in j emitting symbol k ÷ expected times in j

### Pseudocode
```
initialise A, B, π (random / guess)
repeat until P(O|λ) stops improving:
    E-step: compute α, β  (forward/backward)
            compute γ_t(j), ξ_t(i,j)
    M-step: re-estimate π, A, B from γ and ξ
```
With **K sequences**, sum the numerators and denominators over all sequences.

**Notes:** each iteration never decreases P(O|λ), but it can converge to a **local** maximum, so the initial guess matters. Same EM logic as the coin and GMM examples (hidden = state sequence; soft counts = γ, ξ).
